# 📚 Documentação Oficial da Hikari (WhatsApp Edition)

Bem-vindo à documentação oficial da **HikariZap**, a versão para WhatsApp desenvolvida como fork autônomo da [Hikari original para Discord](https://github.com/yGuilhermy/Hikari).

Aqui você encontrará todos os guias técnicos, manuais de configuração, referência de comandos, especificações de arquitetura e instruções para hospedar e personalizar a sua própria instância da Hikari.

---

## 📂 Guias Disponíveis

| Documento | Descrição |
| :--- | :--- |
| [🚀 **Guia de Instalação (Get Started)**](./GET_STARTED.md) | Pré-requisitos, scripts rápidos de setup, dependências de mídia e pareamento via QR Code no WhatsApp. |
| [⚙️ **Configuração & Governança**](./CONFIGURATION.md) | Sistema de validação, controle de proprietário (Multi-Owner), rotação de chaves e provedores de moedas. |
| [🔑 **Guia de Variáveis (.env)**](./ENVIRONMENT.md) | Mapeamento detalhado de cada variável de ambiente, limites aceitos e links oficiais para obter as chaves. |
| [✨ **Funcionalidades & IA**](./FEATURES.md) | Ciclo de vida das mensagens, fila serializada, múltiplos modelos com fallback, visão e function calling. |
| [🎮 **Guia Completo de Comandos**](./COMMANDS.md) | Tabela e exemplos de todos os comandos de chat (`>`), figurinhas, utilitários e painel do proprietário. |
| [🛠️ **Sistema de Ferramentas & Arquitetura**](./ADVANCED.md) | Funcionamento interno do Baileys, fila de mensagens, resolução de identidades PN/LID e criação de novas tools. |
| [🛡️ **Segurança & Moderação**](./MODERATION.md) | Privacidade de dados, sanitização de logs, controles de taxa, proteção contra abusos e travas administrativas. |
| [🖼️ **Processamento de Mídia & Figurinhas**](./MEDIA.md) | Geração de stickers 512×512 com WebP/Sharp, reversão para imagem, downloads com yt-dlp e músicas do Deezer. |
| [🎙️ **Sistema Vocal & Transcrição (STT/TTS)**](./VOICE.md) | Transcrição sob demanda com Whisper (Groq/Wit.ai), síntese neural de voz (TTS) e tutoriais de deploy no Modal/HF. |
